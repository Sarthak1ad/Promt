# 🌡️ Prompt Temperature Demo

## 📌 Objective

This project demonstrates how the **Temperature** parameter affects the responses generated by a GPT-style Large Language Model using the **OpenRouter API**.

Temperature is one of the most important generation parameters in Large Language Models (LLMs). It controls the randomness of the model's predictions. By changing only the temperature while keeping the same prompt, we can observe how the model's responses become more deterministic or more creative.

This experiment helps beginners understand an essential concept of **Prompt Engineering** and how to choose the appropriate temperature value for different AI applications.

# 💬 Prompt Used

```
Explain Artificial Intelligence in simple words.
```

The exact same prompt is sent to the model every time.

Only the **Temperature** value changes.

---

# ⚙ Code Execution

The program sends the same prompt to the GPT model using four different temperature values.

```
Temperature = 0.0

Temperature = 0.3

Temperature = 0.7

Temperature = 1.0
```

After each request, the generated response is printed on the console so the outputs can be compared easily.

# 📊 Effect of Temperature

| Temperature | Response Characteristics |
|-------------|--------------------------|
| **0.0** | Produces highly accurate, deterministic, and consistent responses. The output is factual and almost identical every execution. Best for factual tasks. |
| **0.3** | Produces focused responses with slight variation while maintaining high accuracy. Suitable for technical writing and documentation. |
| **0.7** | Produces balanced responses that are informative, conversational, and creative. Ideal for chatbots and general-purpose AI applications. |
| **1.0** | Produces the most creative and diverse responses. The wording varies significantly and can be imaginative, making it suitable for creative tasks. |

# 🧠 Why Does Temperature Matter?

Language models generate text by predicting the next most probable word.

Temperature changes how these probabilities are sampled.

### Lower Temperature

- Less randomness
- More confidence
- More accurate answers
- Less variation

### Higher Temperature

- More randomness
- More creativity
- More diverse wording
- Less predictable output

Choosing the correct temperature depends entirely on the application's requirements.

# ✅ Conclusion

This experiment demonstrates that the **Temperature** parameter plays a crucial role in controlling the randomness and creativity of GPT model responses.

- **Low temperatures (0.0)** generate predictable, consistent, and highly factual responses, making them ideal for summarization, OCR, information retrieval, and question answering.

- **Medium temperatures (0.3–0.7)** provide a balance between accuracy and creativity, making them suitable for chatbots, educational systems, documentation, and coding assistants.

- **High temperatures (1.0)** encourage imaginative, diverse, and creative outputs, making them ideal for storytelling, brainstorming, marketing content, and creative writing.

Understanding the effect of temperature helps developers select the most appropriate settings for different AI-powered applications and is one of the fundamental concepts in Prompt Engineering.
